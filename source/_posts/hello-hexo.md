写了十几年代码，一直觉得"写博客"这件事对程序员是刚需——不是写给谁看，而是把脑子里的碎片整理成结构的过程。今天终于把这个个人博客搭起来了，用 Hexo + GitHub Pages，写文章就是写 Markdown，`git push` 之后自动发布，符合程序员的一切直觉。

## 这个博客的技术栈

- **Hexo 7**：Node.js 静态博客生成器，模板语法和 Vue 很像，上手零成本
- **GitHub Pages**：免费托管，全球可访问
- **GitHub Actions**：push 自动构建发布，不用在本地敲部署命令
- **landscape 主题**：默认主题，清爽够用，后面看腻了再换

## 接下来会写什么

- Java 后端开发中踩过的坑和最佳实践
- 二十年间技术演进的个人观察（从 Struts 到 Spring Boot 到云原生）
- 一些工具链和工作流的心得

先立个 flag：至少月更。第一个月就撞墙的话……那就当没说过。

> 种一棵树最好的时间是十年前，其次是现在。写博客也一样。
